# Yan-Cheng Li — academic website

A buildless, responsive academic website for GitHub Pages. No dependencies or JavaScript.

## Edit

- `index.html`: biography, news, publication, and contact links.
- `style.css`: layout and typography.
- `assets/portrait.jpg`: profile photo.
- `assets/cv.pdf`: downloadable CV.

The poster URL has not yet been supplied. Replace `Poster forthcoming` in `index.html` with an anchor to the final poster PDF or URL when available.

## GitHub Pages

In the repository's **Settings → Pages**, choose **Deploy from a branch**, branch **main**, folder **/ (root)**. All asset URLs are relative so the page works on a profile domain or project subpath.

## Preview

Run `python3 -m http.server 8000` from this folder and visit http://localhost:8000.
